# 부록 A. 추론 테이블 (외부 스토리지)

추론 테이블(inference table)은 모델 서빙의 요청/응답 페이로드를 자동으로 Delta 테이블에 기록하는 기능입니다. 요청 단위 페이로드 수준의 감사가 필요할 때 사용합니다. 그러나 이 검증 환경(서버리스)에서는 제약에 막혔습니다.

## A.1 Default Storage는 추론 테이블을 지원하지 않는다

서버리스 워크스페이스의 **Default Storage 스키마는 추론 테이블을 지원하지 않습니다.** 페이로드를 기록하려면 외부 스토리지가 필요합니다.

## A.2 외부 스토리지 구성 절차 (일반)

추론 테이블을 쓰려면 다음을 구성해야 합니다.

1. 외부 **ADLS Gen2** 스토리지 계정 준비
2. **Access Connector** 생성 및 스토리지에 대한 권한 부여
3. Unity Catalog에 **외부 카탈로그/외부 로케이션** 구성
4. 서빙 엔드포인트에 추론 테이블을 해당 외부 카탈로그로 지정

## A.3 ⚠️ 서버리스에서의 근본 제약 — 현재 BLOCKED

> **경고** — **서버리스 워크스페이스는 Access Connector를 만들 수 없습니다.** Access Connector는 Hybrid(클래식) 컴퓨트 모드에서만 사용 가능합니다.

따라서 서버리스 워크스페이스에서 외부 스토리지 기반 추론 테이블을 구성하려면 **Hybrid 워크스페이스가 필요**합니다. 현재 이 검증 환경은 서버리스이므로 추론 테이블 구성은:

- **상태: BLOCKED**

추론 테이블 수준의 페이로드 감사가 필수인 경우, 별도의 Hybrid 워크스페이스를 두거나 이 요건을 서버리스 채택 결정 시점에 반영해야 합니다. 사용량·비용 모니터링(본문 4·5장)은 시스템 테이블로 충분히 커버되며, 추론 테이블은 페이로드 감사가 필요한 경우에 한합니다.

> **확인 포인트** — 추론 테이블이 조직 요건인지 먼저 확인하세요. 요건이면 Hybrid 워크스페이스 트랙으로 분기해야 합니다.
